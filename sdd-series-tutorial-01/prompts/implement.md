# Implement Customer Management Service

Read `AGENTS.md` and all documents under `/specs`.

Implement the Customer Management Service inside `/application`.

Treat the OpenAPI specification and acceptance criteria as authoritative contracts.

Before modifying the application, create an implementation plan.

Then:

1. Implement the application according to the specification.
2. Generate the required automated tests.
3. Run the complete test suite.
4. Resolve implementation failures.
5. Verify that the implementation satisfies the acceptance criteria.

Do not modify the specification files.
