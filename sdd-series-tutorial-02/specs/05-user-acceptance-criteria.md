# Acceptance Criteria
- AC-01 Valid create returns generated ID, ACTIVE status and timestamps.
- AC-02 Username uniqueness is case-insensitive.
- AC-03 Email uniqueness is case-insensitive.
- AC-04 Empty roles rejected.
- AC-05 Multiple roles supported.
- AC-06 Existing User retrievable.
- AC-07 Missing User returns not found.
- AC-08 List returns all Users.
- AC-09 Empty list returns an empty collection.
- AC-10 User fields/roles can be updated.
- AC-11 Own username/email can be retained on update.
- AC-12 Another User's username/email cannot be taken.
- AC-13 Status can change ACTIVE/INACTIVE.
- AC-14 Roles can be replaced with a non-empty supported set.
- AC-15 Existing User can be deleted.
- AC-16 Missing delete returns not found.
- AC-17 Tutorial 01 Customer regression tests continue to pass unless explicitly superseded.
- AC-18 No Product, Inventory, Cart, Order, Payment, authentication or messaging is added.
