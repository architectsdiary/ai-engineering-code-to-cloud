# System Context

`mini-ecom-backend` is the long-lived backend application for the Mini E-Commerce series.

Tutorial 02 creates the initial application baseline. Later tutorials evolve the same application through new specification increments.

## Tutorial 02 boundary
Implement only:
- Spring Boot application foundation
- User identity
- User roles
- User lifecycle status
- User REST API
- Persistence
- Validation
- Error handling
- Automated tests
- API documentation support

Logical capability boundaries do not imply separate microservices. The initial system is a modular Spring Boot application.
